Formulas y Metodo de Calculo

1. Resistencia del Conductor (Ida y Vuelta)

R_cable = rho * (2 * L) / A rho = 0.0172 ohm·mm2/m (cobre a 20°C) • L = largo en metros • A = seccion en mm2

Si hay extension: R_total = R_rama + R_extension

2. Resistencia Equivalente de Cargas en Paralelo

R_equipo = Vf^2 / P_nominal 1/R_cargas = Sum (c_j / R_equipo,j)

3. Ley de Ohm en la Rama

R_total = R_cable + R_cargas I_rama = Vf / R_total

4. 2da Ley de Kirchhoff (Malla) - Caida de Voltaje

dV_cable = I_rama * R_cable V_carga = Vf - dV_cable dV% = (dV_cable / Vf) * 100

Verificacion: Vf - dV_cable - V_carga = 0

5. 1ra Ley de Kirchhoff (Nodos)

Nodo Rama: Sum (c_j * I_equipo,j) = I_rama Nodo Tablero: I_total = Sum I_rama,k

6. Ecuaciones de Potencia

P_carga = V_carga * I_rama (Potencia util) P_perdida = I_rama^2 * R_cable = dV_cable * I_rama (Calor/Joule) P_total = Vf * I_total = Sum (P_carga + P_perdida)
